# Physics 2D

Makes layers fall, bounce and hit each other.

1. Select two or more layers (multi-select).
2. Open Plugins (in the bar that appears) and choose Physics 2D.
3. Set gravity, bounciness and which walls exist, then press Run.

Tips:
- Turn on "Pin the first selected layer" to keep one layer fixed, like a platform.
- Rectangles, circles and other shapes collide as their real outline box. The result log tells you which box each layer used.
- Longer layers need more keyframes. Raise "Keyframe every N frames" if you hit the limit.
