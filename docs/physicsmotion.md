# Physics Motion (sample plugin)

`samples/physicsmotion/`, id `kuep.physicsmotion`. Three effects in the Move category and three recipes that add them.
The effects are generated by `tools/gen_physicsmotion.py` (shader source and parameters live there); run it to rebuild
`samples/physicsmotion/effects/`.

This is not a physics simulation. Plain shader effects have no memory between frames, so each effect uses the exact
closed-form motion of one situation. Nothing collides with anything else, and a layer's position and rotation are not
changed: the effect redraws the layer's picture at the displaced place.

| Effect | Motion | Parameters |
|---|---|---|
| Bounce Drop | Falls from above under gravity, bounces with a fixed bounciness until it rests, squashes on each hit | Drop height, Gravity, Bounciness, Squash, Delay |
| Spring Settle | Starts away from its place and a damped spring pulls it in, overshooting | Start X, Start Y, Frequency, Damping, Delay |
| Pendulum | Swings about a pivot, dying away | Start angle, Frequency, Damping, Pivot X, Pivot Y, Delay |

Units: distances (Drop height, Start X and Y) are fractions of the screen height, so a project at another resolution
moves the same way. Gravity is in screen heights per second squared. Pivot is a fraction of the layer's own box.
Time starts when the layer starts. A positive Start angle swings clockwise.

Bounce Drop uses the box of the layer as the floor: the layer comes to rest where it is, and its bottom edge is what
squashes. The drop height is how far above its place it starts.

## Using it

1. Install the zip from the Plugins screen and restart the app (effect packs load at start).
2. Select a layer, open the Effects panel menu, choose Plugin recipes and run a recipe, or add the effect yourself from
   the effect browser (Move).

## Limits

- No collisions between layers, no walls, no rotation from impacts, no dragging by hand. That needs scripts (layer B).
- One effect shows one motion. To drop and then swing, stack effects and use Delay.
- The shaders have been checked against a reference simulation (closed form against a step-by-step integration) and
  drawn with a numpy port, but they have not yet been compiled by the app's Skia build.
